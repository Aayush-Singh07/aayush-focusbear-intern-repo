# Learning Goals — Aayush Kumar Singh

## What Do You Want to Learn & Contribute?

### What do you hope to learn from this internship?
I want real, hands-on depth in React Native and mobile development — a lot of my past project work was built with heavy AI assistance, so I'm using this internship to actually understand the code I'm shipping, not just get it working. I also want to learn how a real product team operates day to day: how features get scoped, reviewed, and shipped in a live codebase with real users.

### What skills are you most excited to develop?
Writing clean, reviewable code and getting comfortable with the full PR/code review cycle — opening PRs, responding to feedback, and reviewing others' code. I'm also excited to get better at debugging real production issues instead of just fixing things in isolation on my own projects.

### What do you think you can contribute to the team?
I move fast and I'm comfortable picking up unfamiliar things quickly — I can take a clearly scoped task and execute on it without needing constant hand-holding. I also bring an analytical/business-adjacent way of thinking alongside the dev work, which sometimes helps in spotting why a feature matters, not just how to build it.

### What is one area you feel less confident in that you'd like to improve?
Testing and deployment — I have very little real experience with structured QA processes, device compatibility testing, or the app store deployment pipeline (TestFlight, Play Console). I understand the concepts but haven't done it hands-on yet.

### What does success in this internship look like for you?
Shipping real, working features that are actually used in the live app — not just completing onboarding tasks. I'd also consider it a success if, by the end, I genuinely understand the codebase well enough to explain and defend decisions in a code review, and if I walk away with a real reference and a clear sense of whether mobile development is a path I want to keep building toward.
