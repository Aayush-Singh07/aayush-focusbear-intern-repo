# Data Privacy & Confidentiality Reflection — Aayush Kumar Singh

## Research & Learn

**Key takeaways from Focus Bear's privacy policy:**
Focus Bear collects user data necessary to provide the app's core functionality (account info, usage/behavioural data to support focus tracking and personalization), is committed to not sharing personal data with unauthorized third parties, and gives users rights over their own data (access, correction, deletion) in line with data protection regulations like GDPR. As an intern with any access to systems or user-related information, the responsibility is to treat that data with the same care the company has publicly committed to.

**Types of data considered confidential at Focus Bear:**
- User personal data (identity, usage patterns, any behavioural/health-adjacent data given the ADHD/Autism focus of the app)
- Internal business information (strategy, unreleased features, internal metrics)
- Credentials, API keys, and access tokens
- Internal communications not meant for public sharing

**Best practices for handling confidential data:**
- Only access data that's actually necessary for the task at hand
- Never copy sensitive data into unsecured tools (personal notes apps, non-approved AI tools, etc.)
- Use strong passwords + 2FA on any account with access to company systems
- Don't discuss specific user data or internal company details outside of appropriate channels, even casually

**Responding to a suspected data breach or accidental disclosure:**
Report it immediately to the team rather than trying to quietly fix it alone — speed of reporting matters more than trying to look like nothing went wrong. Document what happened (what data, how, when) so the team can assess and contain the impact quickly.

## Reflection

**Steps to handle data securely in daily tasks:**
Being deliberate about what data I access and why, never pasting real user data into AI tools or personal notes, and keeping work credentials separate from personal accounts.

**Storing, sharing, and disposing of sensitive information safely:**
Store only in approved company systems, never in personal cloud storage or local unsecured files. Share only through official channels, never via casual chat screenshots containing real user data. Dispose of any local copies (test data, debug logs) once no longer needed rather than letting them accumulate.

**Common mistakes that lead to data privacy issues:**
Using real user data for casual testing/debugging instead of dummy data, oversharing in screenshots that accidentally include sensitive info in the background, and reusing weak or shared passwords for systems with data access. These are avoidable by defaulting to caution — treating any real user data as sensitive until proven otherwise, rather than the reverse.

## Task

**Habit/practice I'm adopting:** Always using sanitized or dummy data when testing/debugging features, rather than real user data, even when it would be slightly more convenient to use real data directly.

**Key learning/security measure I will implement:** Enabling 2FA on all Focus Bear-related accounts (GitHub, Intern Portal, email) and being deliberate about never entering confidential company or user information into any external AI tool or unapproved platform.
