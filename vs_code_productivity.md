# VS Code Productivity — Aayush Kumar Singh

## Top 10 Shortcuts

### Navigation
1. `Ctrl+P` — Quick Open, jump straight to any file by typing its name
2. `Ctrl+Shift+O` — Go to Symbol in the current file, useful for jumping between functions
3. `Ctrl+G` — Go to a specific line number
4. `Ctrl+Tab` — Switch between open editor tabs quickly

### Editing
5. `Ctrl+D` — Select the next occurrence of the current word, keep pressing to select multiple, then edit all at once
6. `Ctrl+Alt+Down` / `Ctrl+Alt+Up` — Add a cursor directly below or above the current line (multiple cursors, genuinely a must have once you get used to it)
7. `Alt+Click` — Add a cursor anywhere you click, for editing multiple unrelated spots at once
8. `Alt+Up` / `Alt+Down` — Move the current line up or down without cutting and pasting
9. `Ctrl+/` — Toggle comment on the current line or selection

### Debugging
10. `F9` — Toggle a breakpoint on the current line
11. `F5` — Start debugging
12. `F10` — Step over the current line while debugging

### Terminal
13. `` Ctrl+` `` — Toggle the built in terminal open or closed
14. `` Ctrl+Shift+` `` — Open a brand new terminal instance

## Reflection

### Which shortcuts do you think will be the most useful in your daily work?
The multiple cursor shortcuts (`Ctrl+D` and `Ctrl+Alt+Down`) are probably the biggest ones for me. A lot of React Native work involves repeating small edits across similar lines like props, style values, or import statements, and editing them all at once instead of one by one saves real time. `Ctrl+P` for quick file jumping is the other one I already lean on constantly, especially in a codebase I'm still getting familiar with.

### How can keyboard shortcuts improve your productivity?
They remove the small friction of reaching for the mouse and hunting through menus for something you do dozens of times a day. On their own each shortcut only saves a few seconds, but across a full day of coding that adds up to a real amount of time and, just as importantly, keeps you in flow instead of breaking focus every time you need to do something routine like open a file or add a breakpoint.
