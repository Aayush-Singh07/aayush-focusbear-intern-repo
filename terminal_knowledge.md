### Which terminal client did you choose? Why?
I've been using Windows PowerShell for a long time already, so I stuck with it rather than switching to something new. It's well integrated with Windows, works fine alongside Git Bash for when I want a more Unix like command style, and I'm already fast and comfortable in it, which matters more to me than switching tools for their own sake.

### What customizations, if any, did you make?
No new customizations for this task specifically since my PowerShell setup was already configured the way I like it from prior use.

### What was the most useful command you learned or used today?
Working through this onboarding repo, the Git commands (`git checkout -b`, `git merge`, resolving conflicts) were the most genuinely useful ones I got real practice with, since those are the commands I'll be relying on daily once I'm actively shipping code as part of the team.
