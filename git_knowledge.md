# Git Setup & Knowledge — Aayush Kumar Singh

### Have you used Git before? If so, in what context?
Yes, I've used Git before for my own personal and freelance projects, but mostly at a basic level, committing and pushing to a single branch without much real branching or PR discipline. As part of preparing for this internship I went through a proper hands-on session on branching, pull requests, code review, and resolving merge conflicts, since I knew that gap would show up quickly working on a real team codebase.

### Which Git client, if any, did you choose? Why?
I use a mix of the Git command line and GitHub Desktop. Command line for most day to day work since it's faster once you know the commands, and GitHub Desktop for things that are easier visually, like reviewing a diff before committing or creating a pull request without digging through GitHub's web UI manually.

### What was the most interesting thing you learned about Git today?
Actually simulating a merge conflict on purpose was the most useful thing, more than reading about it. Once you've caused one deliberately and resolved it yourself, it stops being a scary red error message and just becomes a normal, expected part of working on a branch with others.
