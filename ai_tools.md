# AI Tools for Development — Aayush Kumar Singh

### Which AI tools did you try?
I already use Claude regularly for development work, and I've used it throughout this onboarding process itself, both for learning React Native concepts hands on and for scaffolding some of these onboarding documents. I've also used AI assistants inside my IDE (Antigravity) for running and explaining terminal commands while working through this repo.

### What worked well? What didn't?
AI is genuinely strong at explaining unfamiliar concepts quickly, scaffolding boilerplate, and acting as a first pass on debugging when I'm stuck and not sure where to even start looking. Where it falls short is when I trust it without verifying, since AI generated code can look completely correct and still have a subtle bug that only shows up once you actually run it. I've made a habit of testing everything myself rather than assuming an AI suggestion is correct just because it reads well.

### When do you think AI is most useful for coding?
It's most useful as a fast first draft or a way to unblock myself when stuck, not as a replacement for actually understanding the code I ship. It's especially good for learning a new library or pattern quickly, or for a second opinion when debugging something that isn't obvious. The moment it becomes a problem is when it's used as a substitute for understanding instead of a way to get to understanding faster, which is something I've been actively correcting for in my own workflow.
