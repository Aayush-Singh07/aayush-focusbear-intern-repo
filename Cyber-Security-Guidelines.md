# Cyber Security Guidelines — Aayush Kumar Singh

## Research & Learn

**Common cyber security threats in a remote work environment:**
- Phishing emails/messages impersonating colleagues or trusted services
- Unsecured home Wi-Fi networks (weak/default router passwords)
- Using personal devices without proper security controls for work
- Public Wi-Fi usage (cafes, co-working spaces) without a VPN
- Credential reuse across multiple accounts, so one breach compromises many
- Outdated software/OS with unpatched vulnerabilities
- Shoulder surfing / unlocked devices in shared or public spaces

**Best practices for keeping devices and accounts secure:**
- Use strong, unique passwords for every account (never reused)
- Enable two-factor authentication (2FA) everywhere it's offered
- Keep OS, browser, and apps updated with the latest security patches
- Lock devices automatically after a short idle period
- Avoid clicking links or downloading attachments from unverified senders
- Use a password manager instead of memorizing/reusing passwords
- Avoid public Wi-Fi for sensitive work, or use a VPN if unavoidable

**Why lock your computer when away from your desk:**
An unlocked device is an open door — anyone nearby (family member, roommate, stranger in a public space) could access company data, send messages as you, or install something malicious, all without needing a password. Locking takes 2 seconds; the risk of not doing it is disproportionate to that effort.

**Handling phishing attempts and suspicious links:**
- Check the sender's actual email address, not just the display name
- Hover over links before clicking to see the real destination URL
- Never enter credentials on a page reached via an unsolicited link — go directly to the site instead
- If something creates urgency ("act now or your account will be locked"), treat that urgency itself as a red flag
- Report/flag suspicious emails rather than just deleting them, so others are warned too

**What makes a strong password, and why use a password manager:**
A strong password is long (12+ characters), random (not a dictionary word or personal detail), and unique to that one account. Humans can't realistically remember dozens of unique random passwords — a password manager generates and stores them securely, so you only need to remember one strong master password.

**Why two-factor authentication (2FA) matters:**
2FA means even if your password is stolen (via phishing, breach, or reuse), an attacker still can't get in without your second factor (phone, authenticator app). It should be enabled on every account that supports it, especially email, GitHub, and any work-related tool — since email/GitHub access can cascade into access to everything else.

## Reflection

**What security measures do I currently follow, and where can I improve:**
I already use unique passwords for most important accounts and keep my OS/apps generally updated. My main gap has been inconsistent 2FA adoption across all accounts and not using a dedicated password manager — I've been relying on browser-saved passwords, which isn't as secure or portable as a proper password manager.

**How to make secure behaviour a habit rather than an afterthought:**
Tie it to existing routines — e.g., lock my laptop every time I stand up, the same automatic way I'd lock my phone. Treat 2FA setup as a mandatory last step whenever creating any new account, not an optional extra to "do later." Doing a quick monthly check of which accounts still lack 2FA also helps catch gaps before they become a problem.

**Steps I'll take to secure my passwords and accounts:**
- Set up a password manager (e.g., Bitwarden) and migrate saved passwords into it
- Enable 2FA on all work-related accounts (GitHub, email, Focus Bear Intern Portal)
- Set my laptop and phone to auto-lock after 1-2 minutes of inactivity
- Generate a new, unique password for any account currently using a reused one

**What I'd do if I suspected a security breach or suspicious activity:**
Immediately change the password for the affected account, enable/verify 2FA if not already on, check account activity logs for unrecognized sessions and log them out, and report it to the Focus Bear team right away rather than trying to quietly handle it myself — early reporting limits potential damage far more than a delayed, "fixed it myself" approach.
